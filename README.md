# IPB example area

A fictional island built around the example map in ATP 2-01.3 (Intelligence Preparation of the
Battlefield), as PMTiles for MapLibre and TacTrace. Heights are invented throughout; features
tagged `source=synthetic` are invented as well.

- Preview: https://orbat-mapper.github.io/ipb-example-area/
- TacTrace configuration: https://orbat-mapper.github.io/ipb-example-area/tactrace-config.json
- Example map file: https://orbat-mapper.github.io/ipb-example-area/examples/ATP-2-01.3-IPB.tactrace
- Archives: `out/ipb-vector.pmtiles` (Protomaps schema + `contours`, `mcoo`), `out/ipb-terrain.pmtiles` (terrarium WebP)
- Styles: `style/atp.json`, `style/atp-mcoo.json`
